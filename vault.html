Vault Save

Pola yang sama seperti nfsu2.xyz: save utama tersimpan otomatis di browser perangkat ini. Vault adalah salinan portabelnya, satu file terenkripsi passphrase, untuk cadangan atau pindah perangkat.

Buat file vault (backup)

Seluruh data emulator, termasuk save semua game, dibungkus dan dienkripsi dengan passphrase kamu. Passphrase tidak disimpan di mana pun.

Pulihkan dari file vault

Memulihkan akan menimpa seluruh data save yang ada di browser ini dengan isi file vault.

Catatan: enkripsi memakai Web Crypto bawaan browser (PBKDF2 + AES-GCM 256). Lupa passphrase berarti file vault tidak bisa dibuka lagi, jadi simpan passphrase di tempat aman.
